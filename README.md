# Piano Atelier · أتيليه البيانو

Learn the piano in Arabic and English: a keyboard that lights up with finger numbers for both hands, a real grand-piano sound, treble and bass clef reading, chords, Arabic maqams, and a site that listens to you play (microphone or MIDI).

- Visitors and members: https://piano-atelier.github.io
- Piano sound: Salamander Grand Piano by Alexander Holm, CC BY 3.0.
- Staff symbols: Bravura by Steinberg, SIL Open Font License.
